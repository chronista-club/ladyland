# X-Touch Surface

本体を **MC / USB** にし、設定（⌘,）の「MIDI機材」でX-TouchをLadylandに割り当てる。
右側の **X-Touch** タブ、またはその別ウィンドウで操作する。

- 左8本: 内部64トラックのうち表示中の8トラック。フェーダーは音量、上段ノブはPan。ノブを押すと中央へ戻る。
- FADER BANK: ±8トラック。CHANNEL: ±1トラック。端で停止する。
- Select: 演奏先のTrackを選択。Mute/SoloはTrack単位。表示範囲の移動だけでは演奏先を変えない。
- 右1本のMaster: 全体音量（ドラムを含む）。Bank/Channelで担当は変わらない。
- 初版の音量は0–100%（100%=gain 1）。実機に印刷されたdB目盛との校正は未対応。

接続・再接続時はLCDと色を短く表示し、復元済みのTrack名・色・音量へ同期する。
受信したタッチ状態がONのフェーダーにはモーター位置を送らない。
タッチ中のBank/Channel移動は、手を離してから反映する。
モーターから返る値は音量へ戻さず、物理操作はタッチ中だけ受ける。

Pan / Solo / Masterも他のラック設定と同じSQLiteへ保存する。未接続時も画面で編集できる。
通信はMidistage経由。X-Touch EXTを鍵盤として扱わない。
Transport・プラグインパラメーター割り当ては初版の対象外。
