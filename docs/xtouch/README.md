# X-Touch Surface

本体を **MC / USB** にし、設定（⌘,）の「MIDI機材」でX-TouchをLadylandに割り当てる。
右側の **X-Touch** タブ、またはその別ウィンドウで操作する。
Jack／VirtualDeskでは、上部の **X-Touch → Mixer Surface** から同じ操作面を開く。
操作面の **割当一覧** を開くと、現在の動作と未割当の操作子を確認できる。未接続でも参照できる。

## 現在の割当一覧

対象はmacOS版LadylandのX-Touch Surface（MC / USB）。8列の担当は内部64トラックの表示範囲に従う。
「実機確認済み」はユーザーの操作報告があるもの。「実装済み」はコード・自動テストの確認で、実機確認とは区別する。

| 操作子 | 現在の動作 | 状態 |
|---|---|---|
| REC ×8 | 未割当。録音待機／録音機能の範囲は検討中 | 未実装 |
| SOLO ×8 | 担当TrackのSoloを切替。複数Solo可。Solo以外を消音し、元のGain/Muteは保持 | 実装済み・LED連動 |
| MUTE ×8 | 担当TrackのMuteを切替。解除で元のGainに戻る | 実装済み・LED連動 |
| SELECT ×8 | 担当Trackを選択。選択追従の演奏入力・編集対象が切り替わる | 実装済み・LED連動 |
| FADER BANK ◀ / ▶ | 表示範囲を8Trackずつ移動 | 実機確認済み |
| CHANNEL ◀ / ▶ | 表示範囲を1Trackずつ移動 | 実機確認済み |
| 上段ノブ ×8：回す | 担当TrackのPanを左右へ変更 | 実装済み・LEDリング連動 |
| 上段ノブ ×8：押す | Panを中央へ戻す | 実装済み |
| フェーダー ×8 | 担当Trackの音量。保存値へモーター同期 | 実装済み |
| MASTERフェーダー | ドラムを含む全体音量。Bank移動の影響を受けない | 実装済み |
| フェーダータッチ ×9 | 触れている間のモーター送信を停止。Bank移動は手を離すまで保留 | 実装済み |

表にないボタンは未割当。Transport（REW/FF/STOP/PLAY/REC）、ノブのASSIGN切替、
F1–F8、オートメーション、修飾キー、カーソル／ZOOM／SCRUB、ジョグダイヤルなどはまだ操作に使わない。
各TrackのRECとTransportのRECは別のボタンで、どちらも現状は録音を開始しない。

## 表示・フィードバック

| 表示 | 内容 | 状態 |
|---|---|---|
| LCD上段 | 担当Track名（7文字、ASCII外は `?`） | 実装済み |
| LCD下段 | 音量のパーセント表示 | 実装済み |
| LCD背景色 | Trackカラーを対応する8色へ近似。未設定は白 | 色の実機表示確認済み |
| 接続演出 | 起動・再接続時に約0.8秒のカラー表示、その後に通常表示 | 再接続時の実機確認済み |
| SOLO / MUTE / SELECT LED | 表示中の担当Trackの状態 | 実装済み |
| LEDリング | Panの位置 | 実装済み |
| レベルメーター／タイム表示 | 未送信 | 未実装 |

LCDの色はTrack面の名前横の色チップで設定する。起動演出の配色は固定。

## 操作と保存

- 左8本: 内部64トラックのうち表示中の8トラック。フェーダーは音量、上段ノブはPan。ノブを押すと中央へ戻る。
- FADER BANK: ±8トラック。CHANNEL: ±1トラック。端で停止する。
- Select: 演奏先のTrackを選択。Mute/SoloはTrack単位。表示範囲の移動だけでは演奏先を変えない。
- 右1本のMaster: 全体音量（ドラムを含む）。Bank/Channelで担当は変わらない。
- 初版の音量は0–100%（100%=gain 1）。実機に印刷されたdB目盛との校正は未対応。

接続・再接続時はLCDと色を短く表示し、復元済みのTrack名・色・音量へ同期する。
受信したタッチ状態がONのフェーダーにはモーター位置を送らない。
タッチ中のBank/Channel移動は、手を離してから反映する。
モーターから返る値は音量へ戻さず、物理操作はタッチ中だけ受ける。

Pan / Solo / Masterも他のラック設定と同じSQLiteへ保存する。未接続時も画面で編集できる。
通信はMidistage経由。X-Touch EXTを鍵盤として扱わない。
Transport・プラグインパラメーター割り当ては初版の対象外。
