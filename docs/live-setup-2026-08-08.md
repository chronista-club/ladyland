# 8/8 大阪ライブ — ladyland セットアップ手順書

> design/06 §6 の出口条件「セットアップ手順書どおりに音が出る」の実体。
> 8/8 当日はこの手順を上から順に実行する。リハ（30 分通し）もこの手順で入る。
> 価値基準: ①確実に動く ②後から何が起きたか分かる（design/06 §1）

## 0. 持ち物

- MacBook（M5 / 24GB、ladyland ビルド済み・KORG 認証済みであること）
- ZOOM L6max（物理ミキサー = 出音の出口）+ 電源
- KORG Keystage（鍵盤 + ノブ 8）+ USB ケーブル
- AKAI LPD8（第 2 の声部）+ USB ケーブル
- 予備 USB ケーブル / USB ハブ（ポート数に注意）
- `rack.json` のバックアップ（下記 §5。**セット一式の持ち運び = このファイル 1 個**）

## 1. 接続（順序は任意、起動前に全部挿す）

1. L6max を電源に繋ぎ、PA へ出力を接続
2. Mac ↔ L6max（USB — オーディオインターフェースとして見える）
3. Mac ↔ Keystage（USB）
4. Mac ↔ LPD8（USB)

## 2. 起動と起動時チェック

```bash
# 本番は /Applications の Ladyland.app から（Spotlight で "Ladyland"）。
# 直前にコードを触ったなら、積み込みは必ず --reinstall（終了 → release ビルド → 差し替え → 起動）
cd ~/repos/ladyland
scripts/build-app.sh --reinstall
```

（**CLI 直起動（`swift run`）は本番では使わない** — ⌘Q も終了時保存も効かず、TERM 落ちで状態を失った実例がある。
切り分けで使うときも **必ず `-c release Ladyland`** — `swift run` 単体は RigBench と曖昧でエラー、debug ビルドは負荷の余裕が別物）

起動したら **Console.app（または実行ターミナル）の NSLog で 3 点を確認**:

| ログ | 意味 | 出ないとき |
|---|---|---|
| `output: ZOOM L6max に固定` | 出音の出口が L6max | L6max の USB を挿し直して再起動。不在時は OS 既定へ fail-open（音は Mac 内蔵から出る） |
| `MIDI sources: Keystage … → keyboard, LPD8 → drums` | 両機材が見えている | ケーブル確認。ホットプラグ対応なので挿せば自動再接続 |
| `restore: N slots restored` | 前回のラックが戻った | 初回起動なら出ない（正常）。§5 のバックアップから復旧可 |

GUI: 8 スロットに前回の楽器が並び、選択中スロットに枠が付いていること。
**選択中スロットが「無音」警告（黄）のときは楽器が入っていない — 弾く前に必ず解消**。

LED: LPD8 のパッドがキー・スケールの色（ルート橙 / スケール内 青）で点く。
点かない場合は設定 → LPD8 → 「パッド LED フィードバック」を確認（§4.5）。

## 3. 発音チェック（1 分）

1. Keystage を弾く → 選択中スロットのレベルメーターが振れ、L6max から音が出る
2. 数字キー 1-8 / ← → で持ち替え → 旧楽器の余韻が残り、新楽器が鳴る
3. LPD8 を叩く → ドラムスロット（右端）が鳴る — 持ち替えの影響を受けない
4. ↑↓ で選択中の音量が動く（メーターも追従 = post-fader）

**音が出ないときの切り分け**（過去実績のある順）:

- `LADYLAND_SELFTEST=1 swift run -c release Ladyland` — MIDI なしで Memphis を自動発音。RMS ログが出れば音声グラフは正常 = 犯人は MIDI か空スロット
- KORG が鳴らない = **このマシンで KORG 認証が済んでいるか**（未認証はロード成功なのに無音。KORG Gadget を一度起動して認証）
- クラッシュしたら `~/Library/Logs/DiagnosticReports/*.ips` を最初に見る
- Splice はカタログから遮断済み（deny list）— 出てきたら逆に異常

## 4. 顔つまみ（Keystage ノブ 8、P4 実装）

- スロットの **ダイヤルアイコン**（ロード済みスロットに表示、割当ありは brand 色）→ ノブ 1-8 に AU パラメータを割当（検索可）。**楽器ごと 2〜4 個が目安**
- 割当は rack.json に保存され、再起動後も残る
- **ピックアップ動作**: 持ち替え直後はノブを回しても効かないことがある — ノブがパラメータ現在値の位置を「拾う」まで回す（値が跳ばないための仕様）
- ノブ CC は位置固定。**PAGE -/+ で P1〜P8 = CC0-63 の 64 席が全部使える**
  （ladyland の P1 = デバイスのページ 1 で番号が一致する）
- ⭐ **未割当のノブを回しても楽器には届かない**。CC0-63 は**割当の有無に関係なく
  全部飲む**ので、**音量が飛ぶ・音色が変わるといった事故は起きない**
  （Mod ホイールは CC116、Damper は CC64、Expression は CC115 へ逃がしてある —
  こちらは今までどおり楽器へ届く）

## 4.5 設定ウィンドウ（gear ボタン / Cmd+,）

非モーダル — 開いたまま演奏できる。確認して閉じる。

- **オーディオ出力**: 会場では「既定（L6max 優先）」のままで良い（L6max を名前で自動 pin）。
  別インターフェースに出したい時だけ一覧から選ぶ（切替時に一瞬音が途切れる）。
  選択は保存され、次回起動で再適用（不在なら既定へフォールバック — 挿し忘れ安全）
- **LPD8 タブ**:
  - 「パッド LED フィードバック」= **ステージの非常口**。LED が不審な動きをしたら
    ここをオフ（即全消灯、演奏経路には無関係）
  - **プログラムエディタは本番セット中に使わない**（サウンドチェック・自宅用の道具。
    SET は実機設定を上書きする）
  - LED の上書き表示は LPD8 を**挿し直すと本体設定の色に戻る**（仕様）
- **キー・スケール**: 本番の曲キーに合わせるとパッドの色分けが道しるべになる
  （ルート = 橙 / スケール内 = 青 / 外 = 消灯）。設定は保存される

## 5. ラックのバックアップ（リハ後・本番前に必ず）

```bash
cp ~/Library/Application\ Support/ladyland/rack.json ~/Desktop/rack-$(date +%m%d).json
```

楽器構成 + 音色 (fullState) + 音量 + 顔つまみ割当 + 出力デバイス + キー/LED 設定の
全部がこの 1 ファイル。壊れた場合は逆コピーで復旧 → 再起動。

**LPD8 本体のバックアップ**（実機側の設定はこのファイルに入らない）:
設定 → LPD8 → 読み込み → プリセット名を付けて保存。
`~/Library/Application Support/ladyland/profiles/lpd8/` に JSON で残る —
ライブ用 4 プログラムを一度ずつ読んで保存しておけば、実機が飛んでも復元できる。

## 6. 終了

Cmd+Q（終了時に LED 全消灯 → 自動保存の順。`rack saved:` ログで確認可能）。
パッドが消灯したままなのは正常 — 本体設定の色に戻すには LPD8 を挿し直す。
