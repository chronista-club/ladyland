# ROTO 抽出時に引き継ぐ実測と制約

2026-09-05、`feature/refactor-appstate-startup` の純粋層抽出に伴う整理。
元の記録は `eb17d7f:ladyland/Sources/Ladyland/MIDI/RotoService.swift`。
レビュー: Creo `mem_1CejRww9ihs8Z8zk4KxkvE`。
以下の実測日は過去の確認日であり、今回の変更を実機確認した日ではない。

通信の全体像は [protocol.md](protocol.md)、MIDI冊の書き込みは
[admin-port.md](admin-port.md)。コードのコメントには制約を短く残し、経緯をここに置く。

## ページ座標

担当: `RotoPageLayout` / `KnobPages`。

- 2026-08-04、Logic SMART面で「デバイスセル0–7=P1、8–15=P2」を試すと、
  LCDはP1なのにノブでP2のパラメータが動いた。表示する番号と入力で名乗る番号は
  一致しない。前後半に同じ8個を重ね、ページ移動はホストが管理する。
- 2026-08-08の監査B-1/B-9と08-09の実機確認では、危険CCを後ろに並べた
  `assignableCCs` を8個ずつ切ると、P1からCC0/7が抜けてCC8/9が混ざった。
  正典は `KnobPages.pages`（ページ=CC÷8）。ROTOとKeystageは同じ位置で同じCCを扱う。

## LCD の表示

担当: `RotoDisplay`。

- 2026-08-05、ノブLCDは折り返さず12文字1行だった。名前とページタグが
  空白1個を含めて収まるときだけ併記し、それ以外はパラメータ名を優先する。
- 空文字では前の表示が残る。2026-08-06裁定は「空席色 + `-`」。短いhyphenを
  用い、em dashへ置換しない。空席へのページタグは割当があるように見えるため付けない。
- 2026-08-06、MAIN LCDの2行目への表示が開通。1行目はデバイス所有。
  2行目はトラック名を先に読み、ページを右端で拾える配置にする。
  `[1]`から`#1`に替えたのは名前へ1文字回すため。名前が溢れてもページは残す。
- 同日、`Phoenix (Analog)`を直接切ると`Phoenix (`が残ったため、括弧内の
  カテゴリを先に除く。切り口の空白・記号も取り除く。
- MAIN LCDの文字は白固定。同日、白地に白文字で読めないことを実測した。
  背景を自動で暗くする案の後に「設定で変えたい」と裁定され、現在は選択したRGBを
  そのまま送る。白文字の制約を残しつつ、自動減光を復活させない。

## 送信と影

担当: `RotoProjection` / `RotoService` / `RotoShadow`。

- `af653d6`では公式`config.lua` L1592に合わせて空セルを送らなかったが、
  2026-08-06に空セルを送ると残像が消え、ノブ活性も壊れないことを実機確認した。
  現在は `LADYLAND_FILL_EMPTY` 未指定で送る。`=0`が退避路で、残像と引き換えに
  空セル送信を止める。空ノブへのモーター値を止める `PARK_EMPTY_KNOBS` とは別の門。
- 空セル送信を止めても、割当はあるが表示名を解決できないセルは送る。
  `isMapped`と名前の有無を同じ判定にしない。
- MAIN LCDは「据える→文字→色」。2026-08-06の実測で据え直しは無視されたため、
  影が空の初回だけ据える。文字が同じでも色が変われば再送する。
- Bitwigのトラック一覧は枠付きバッチと選択通知を一組にする。
  方言を跨いで送信形式を混ぜない。

## 受信の観測

担当: `RotoShortRoute` / `RotoService.handleShort`。

- 2026-08-04の依頼は「発信されたか、Ladylandの使用箇所まで届いたか」の区別。
  入口と適用側のログを対にする。ノブを毎イベント記録すると1回転100行以上になり、
  ファイル書き込みも増えるため間引く。
- 2026-08-06、値ストリームを全廃すると「未達」と「受信後に弾いた」を区別できず、
  touchだけが残った。現在はDAWのch15 CC0–63を1秒1行にし、その他の受信も残す。
  MIDIモードは同期帳簿・適用側の別ログを使う。
- 「矢印が喋らない」はSMART/PLUGIN面での測定。2026-08-11にはMIX面で
  ch16 CC60/61を確認した。否定測定には面・方言・日付を付ける。
- ch2はMIDIモードが全て受け止める。現行はCC0–63がgain、64–127が選択ボタン。
  `midiModeIgnored`は将来この範囲に隙間ができた場合の防御で、現在の入力では到達しない。

## この抽出の確認範囲

`RotoProjectionTests` は送信列・順序と影、`RotoShortRouteTests` は入力の優先順位、
`RotoValue14Tests` はMSB保持を検証する。これらは実機の表示・モーター確認を代替しない。

実機確認では起動版とフラグ、ROTOの面・方言を記録する。既定のMIDI運用と、
`LADYLAND_ROTO_FULL=1`のSMART/MAIN LCD投影は別条件。
既定でSMART投影が出ないことを今回の回帰と扱わず、旧版と同じ条件で比較する。
確認するのはページとノブの対応、SMART表示、MAIN LCD 2行目、MIXノブgain。
