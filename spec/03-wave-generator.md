# wave-generator 仕様書

> オーディオビジュアライザー＆ムービー出力システム

## 概要

1時間のサウンドファイルをリアルタイム再生しながら、MIDI 2.0コントロール（Korg Keystage）でビジュアルを操作し、HD動画として録画するシステム。

| REQ-CORE-003 | 統一エラー型 | エラーハンドリングの統一 |

## REQ-CORE-001: コアデータ型定義

**概要**: システム全体で共有されるデータ型とトレイトを定義

**背景**: 各クレート間でデータをやり取りするための共通型が必要

**受け入れ条件**:
- [ ] AudioFrame構造体が定義されている
- [ ] AnalysisData構造体が定義されている
- [ ] ShaderUniforms構造体がGPU転送可能（Pod/Zeroable）

**関連設計**: design/02-wave-generator-architecture.md

---

## REQ-AUDIO-001: オーディオファイルデコード

**概要**: symphoniaを使用して各種オーディオファイルをデコード

**背景**: WAV/MP3/FLAC等の一般的なフォーマットをサポート

**受け入れ条件**:
- [ ] WAVファイルをデコードできる
- [ ] MP3ファイルをデコードできる
- [ ] デコード結果をAudioFrameとして返す
- [ ] サンプルレートとチャンネル数を取得できる

---

## REQ-AUDIO-002: オーディオ再生

**概要**: cpalを使用してオーディオをリアルタイム再生

**背景**: デコードしたオーディオをスピーカーに出力

**受け入れ条件**:
- [ ] デフォルトオーディオデバイスで再生できる
- [ ] 再生/一時停止を制御できる
- [ ] 再生位置を取得できる
- [ ] バッファアンダーランを適切に処理

---

## REQ-AUDIO-003: オーディオ解析

**概要**: FFTとビート検出によるオーディオ解析

**背景**: ビジュアルをオーディオに反応させるためのデータ抽出

**受け入れ条件**:
- [ ] FFTでスペクトラムを取得
- [ ] 周波数帯域（低/中/高）のエネルギーを計算
- [ ] ビートを検出
- [ ] RMS/ピークレベルを計算

---

## REQ-VISUAL-001: GPUレンダリング

**概要**: wgpuを使用したGPUベースレンダリング

**背景**: 60fps以上のリアルタイムレンダリングが必要

**受け入れ条件**:
- [ ] wgpuでウィンドウにレンダリング
- [ ] 1920x1080@60fpsを維持
- [ ] フレームバッファを動画エンコード用に取得可能
- [ ] ウィンドウリサイズに対応

---

## REQ-MIDI-001: MIDI入力処理

**概要**: midirを使用したMIDI入力の受信と処理

**背景**: Korg Keystage等のMIDIコントローラーでビジュアルを操作

**受け入れ条件**:
- [ ] MIDIデバイスを検出・一覧表示
- [ ] 指定したポートに接続
- [ ] Note On/Off, CC, ピッチベンドを受信
- [ ] 非同期でイベントを処理

---

## REQ-ENCODER-001: 動画エンコード

**概要**: video-rsを使用したH.264/MP4エンコード

**背景**: 1時間の連続録画が必要

**受け入れ条件**:
- [ ] 1920x1080@60fpsでエンコード
- [ ] H.264コーデックを使用
- [ ] 1時間連続録画でメモリリークなし
- [ ] ドロップフレームを最小化

---

## 入力仕様

### オーディオファイル

| 項目 | 仕様 |
|------|------|
| フォーマット | WAV, MP3, FLAC, OGG |
| サンプルレート | 44.1kHz〜192kHz |
| ビット深度 | 16bit〜32bit float |
| チャンネル | モノラル/ステレオ |

### MIDIデバイス

| 項目 | 仕様 |
|------|------|
| プロトコル | MIDI 1.0（将来的にMIDI 2.0） |
| メッセージ | Note On/Off, CC, ピッチベンド, アフタータッチ |
| コントロールチェンジ | CC 0-7をシェーダーパラメータにマッピング |
| シーン切り替え | ノート60-67（C4-G4）でシーン選択 |

---

## 出力仕様

### 動画

| 項目 | 仕様 |
|------|------|
| 解像度 | 1920x1080 (Full HD) |
| フレームレート | 60fps |
| コーデック | H.264 |
| コンテナ | MP4 |
| ビットレート | 20 Mbps |
| 最大長 | 1時間以上 |

---

## 操作仕様

### キーボード

| キー | 機能 |
|------|------|
| Space | 再生/一時停止 |
| R | 録画開始/停止 |
| 1-8 | シーン切り替え |
| Esc | 終了 |

### MIDIマッピング（デフォルト）

| CC | パラメータ |
|----|-----------|
| 0 | 回転速度 |
| 1 | モジュレーション（組み込み） |
| 2 | 色相オフセット |
| 3 | グロー強度 |
| 4 | リング数 |
| 5 | ズームレベル |
| 6 | ディストーション |
| 7 | 明るさ |
